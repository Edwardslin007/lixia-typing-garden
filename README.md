# 立夏的打字小花园 V1.0

公网地址：https://edwardslin007.github.io/lixia-typing-garden/

进入网页后输入账号名 `lixia`。当前只开放这个账号；没有密码，账号名属于家庭场景下的轻量识别入口。

保留 25 个键位关卡、20 字拼音拼写、笔记本全键位教学、中文／英文／键位知识考试、摘星游戏、独立排行榜、成长积累和小红花。

## 数据与账号

- 页面由这个公开仓库的 GitHub Pages 托管。
- 配套私有数据仓库：`Edwardslin007/lixia-typing-garden-data`。
- 每个账号有独立记录：`accounts/<账号名>/state.json`，目前为 `accounts/lixia/state.json`。
- Cloudflare Worker 负责账号名校验、签发会话、读写 GitHub。网页没有 GitHub Token 或 MiMo 密钥。
- 浏览器先保存账号独立的本机副本，约 8 秒停止输入后同步；持续练习时定期同步，完成关卡、考试或游戏会优先同步。
- 页面显示“已同步到 GitHub”后表示 GitHub 已确认写入。断网时显示本机已保存，联网或下次进入同账号后会继续同步。
- 两台设备发生版本冲突时合并学习记录并重新保存，GitHub 保留提交历史。
- 在原本的本机网页登录 `lixia`，会合并原先本机练习记录；公网浏览器不能直接读取另一来源的本机数据。

仅账号名不是强身份认证：知道 `lixia` 的人也可进入和修改该账号记录。私有仓库防止直接公开浏览，不等同于密码保护网页入口。

## V1.0 封版

Git 标签：`v1.0.0`。GitHub Release 附带封版 ZIP 与 SHA-256 文件清单。代码与音频在发布时冻结；本机密钥、备份、开发缓存不包含在发布包里。

首次使用：登录 → 先去“键盘教学” → 再练基本键位或“拼音拼写”。拼音练习使用英文输入法，不打声调，ü 用 v。

账号右侧“立即同步”可主动保存；“退出账号”会先尝试同步再退出。需要完整离线备份时仍可使用设置中的记录备份。

## 部署与维护

`main` 分支更新后，GitHub Actions 构建并部署 `dist` 到 Pages。构建脚本为 `tools/build_pages.py`。Worker 源码和非敏感配置在 `cloud/`；Worker Secret 使用 Cloudflare 加密保存。

增加账号时需在 Worker 配置的 `ALLOWED_ACCOUNTS` 中加入账号名，并在私有数据仓库建立对应账号记录；每个账号继续使用独立文件，不共享进度。

动态语音仍使用 MiMo 茉莉女声。键位教学、汉字读音和常用提示已录制，新的考试回答／星星成绩提醒由限定语句范围内的云端 MiMo 生成并缓存。
